# 01 — Technical SEO

Foundations that apply to every page. If any of these regress, all
downstream content work loses value.

## 1. `index.html` head contract

The static head is the **fallback** every crawler sees (including no-JS
crawlers like LinkedIn/Slack/FB). Per-route overrides happen via
`react-helmet-async` — see [03-per-route-meta](./03-per-route-meta.md).

Required tags (current state ✅ unless flagged):

- `<meta charset="UTF-8">` ✅
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` ✅
- `<title>` — sitewide brand title ✅
- `<meta name="description">` — sitewide pitch, < 160 chars ✅
- `<link rel="canonical" href="https://barberhub-tv.lovable.app/">` ❌ **missing — add**
- `<meta property="og:title|og:description|og:image|og:type|og:site_name">` ✅
- `<meta property="og:url" content="https://barberhub-tv.lovable.app/">` ❌ **missing — add**
- `<meta name="twitter:card|twitter:title|twitter:description|twitter:image">` ✅
- `<meta name="theme-color" content="#0a0a0f">` ❌ **missing — add (matches Deep Black brand)**
- Favicons + webmanifest ✅
- Sitewide JSON-LD (Organization + WebSite + SearchAction) ❌ **missing — add, see [02](./02-schema-jsonld.md)**

When adopting Helmet at the route level, **remove `<link rel="canonical">` from `index.html`** — `<link>` tags don't dedupe and you'll ship two canonicals. Keep sitewide `og:*` as the no-JS fallback.

## 2. robots.txt

`public/robots.txt` currently allows all crawlers (good). Add the
`Sitemap:` directive so crawlers don't have to guess the well-known
path:

```
User-agent: *
Allow: /

Sitemap: https://barberhub-tv.lovable.app/sitemap.xml
```

Disallow rules to keep in mind (add if these routes ever become indexable):

- `/sovereign-hq` and `/admin/*` — internal, must never be crawled.
- `/auth/callback`, `/reset-password` — utility routes, no SEO value.
- `/payment-success`, `/payment-canceled` — utility, no SEO value.

These are currently not linked from public pages so they don't get
indexed in practice, but defense-in-depth wins.

## 3. Sitemap

- Generated by `scripts/generate-sitemap.ts`, runs on `predev` + `prebuild`.
- Output: `public/sitemap.xml`. Never hand-edit.
- 186 entries today: 1 hub + 25 cities + 150 service pages + 35 static/app routes.
- **When to extend:** any new public route, any new published row of dynamic content (new city, new service slug, new evergreen tournament page).
- Add `<lastmod>` on city/service pages when copy meaningfully changes — improves recrawl frequency.

## 5. Performance hints already shipped

```html
<link rel="preconnect" href="https://videodelivery.net" crossorigin>
<link rel="preconnect" href="https://cloudflarestream.com" crossorigin>
<link rel="dns-prefetch" href="https://r2.cloudflarestorage.com">
```

Add new `preconnect` entries when introducing a new critical-path
third-party origin. Cap total preconnects at ~4 — more hurts than
helps.

## 6. Crawl-budget rules

- Programmatic city/service pages: ~150 today. Safe to grow to ~2,500
  before crawl budget becomes a concern. Past that, gate behind
  `<lastmod>` and split into multiple sitemaps.
- Never let user-generated pages (battles, profiles) leak into the
  sitemap unless they're guaranteed evergreen (battle ended, profile
  not banned). Today only `/barber/:userId` for verified barbers and
  `/tournaments/:id` for finished tournaments belong there — add a
  filter in the generator before enabling.

## 7. HTTPS, redirects, trailing slashes

- Canonical host: `barberhub-tv.lovable.app` (no `www`).
- All `http://` → `https://` 301s handled by the host.
- No trailing slashes on programmatic URLs. The generator and Helmet
  canonicals already enforce this — keep it consistent in internal
  links.
